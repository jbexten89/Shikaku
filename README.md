# Shikaku

A Shikaku logic puzzle game: divide the grid into rectangles so each one contains exactly one number equal to its area.

Single-file web app (vanilla HTML/CSS/JS), built for the iPhone home screen via GitHub Pages.

- Easy 5×5, Medium 7×7, Hard 10×10, Expert 12×12, plus a date-seeded Daily puzzle
- Every puzzle is generated with a unique solution
- Drag to draw, tap to remove, undo/redo, hints, timer, stats and daily streak
- Progress and stats are saved on-device (localStorage)

Play: https://jbexten89.github.io/Shikaku/
