# Shikaku

Two puzzles in one app: **Shikaku** and **Tatamibari**.

A Shikaku logic puzzle game: divide the grid into rectangles so each one contains exactly one number equal to its area.

Single-file web app (vanilla HTML/CSS/JS), built for the iPhone home screen via GitHub Pages.

- Easy 5×5, Medium 7×7, Hard 10×10, Expert 12×12, plus a date-seeded Daily puzzle
- Every puzzle has a unique solution, and difficulty is set by the reasoning it requires (not just grid size)
- Tatamibari mode: shape clues (+ square, – wide, | tall) and no four rectangles meeting at a corner
- Optional Mystery clues (?) for Shikaku Medium/Hard/Expert
- Works offline once loaded; magnifier for dragging on Hard/Expert; pause; optional mistake highlighting; three color palettes
- Drag to draw, tap to remove, undo/redo, hints, timer, stats and daily streak
- Progress and stats are saved on-device (localStorage)
